# Synthesizer

A browser-based subtractive synthesizer with a 16-step pitched sequencer, built with React, TypeScript, and Tone.js.

- Two oscillators (sine/square/triangle/sawtooth) with detune and volume
- Multi-mode filter (low/high/band-pass) with cutoff and resonance
- Independent amp and filter envelopes (ADSR)
- 16-step sequencer — click a step to toggle it, drag vertically to set its pitch

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```
